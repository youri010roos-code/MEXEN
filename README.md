# 🎲 Mexen

Online versie van het dobbel- en drankspel Mexen. Eén scherm dat rondgaat in de groep.

## Spelen

Open `index.html` in je browser, of speel via GitHub Pages (zie hieronder).

- Vul de namen in (minimaal 2 spelers, geen maximum)
- Kies je huisregels: Anaalridder, 32 = direct verloren, start-inzet
- Geef de telefoon door aan wie aan de beurt is
- Op een laptop werkt de **spatiebalk** als "gooi / volgende"

De stand blijft bewaard als je de pagina ververst.

## Regels

- De eerste speler gooit max. 3 keer en mag eerder stoppen. De rest mag max. net zo vaak gooien.
- **Mex (21)** is het hoogst en verdubbelt de inzet. Daarna komen dubbels (600 tot 100), daarna de overige worpen (65 tot 31).
- De laagste score drinkt. Bij gelijkspel volgt een beslissende worp. De verliezer begint de volgende ronde.
- **🐴 Anaalridder:** wie 1+1 gooit, wordt ridder. Bij elke dubbele worp van wie dan ook drinkt de ridder het aantal ogen. Dat duurt tot iemand anders 1+1 gooit.

## Online zetten met GitHub Pages

1. Maak een nieuwe repository op GitHub, bijvoorbeeld `mexen`
2. Upload `index.html` en `README.md` (via **Add file → Upload files**)
3. Ga naar **Settings → Pages**
4. Kies bij *Source*: **Deploy from a branch**, branch `main`, map `/ (root)`, en klik op **Save**
5. Na ongeveer een minuut staat het spel op `https://<jouw-gebruikersnaam>.github.io/mexen/`
